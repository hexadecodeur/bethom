# BeThom

BeThom est un **site vitrine** simple et efficace pour présenter le profil de Thomas, graphiste freelance, ses projets et permettre le contact.
- Site *responsive*, images *optimisées*, *favicon*, et *métadonnées de base*.
- Validation **W3C**.
- Conforme à la maquette **Figma** créée par le graphiste.
- Utilisation d'*ancres* dans le menu pour faire défiler vers les *sections*.

---

## Aperçu

- **Accueil** - Présentation du professionnel.
- **Blog** - Description des différentes méthodes utilisées par le graphiste.
- **Portfolio** - Exemples de créations.
- **Contact** - Coordonnées.

---

## Instructions d'installation locale

- Installer et ouvrir l'éditeur de code **VSCode**

- Installer l'extension *Live Server*

- Dans le terminal:
```bash
git clone https://github.com/hexadecodeur/bethom.git
```
- Ouvrir la page web en local avec le bouton "**Go Live**" en bas à droite

## Police utilisée

Le projet utilise la police **Heebo**, chargée via Google Fonts.

Aucune installation manuelle n'est nécessaire.

La police est importée dans le `<head>` du fichier HTML :

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Heebo:wght@100..900&display=swap" rel="stylesheet">
```
